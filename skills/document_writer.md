# Document Writer & Formatter Skill

When the user asks you to write a document, portfolio, proposal, or article:

## Recommended Fast Workflow:
1. **Target Identification**:
   - If Google Docs is requested: use `open_url` with `https://docs.google.com` or launch browser.
   - If local document/Notepad is requested: use `write_file` for direct creation, or `open_app` with `notepad`.
2. **Content Generation & Layout**:
   - Structure document with clean headings, executive summaries, bullet points, and actionable sections.
   - For fast writing in GUI apps, use `type_text` with `paste: true` to insert formatted blocks instantly.
3. **Review & Finalize**:
   - Verify on-screen content layout.
   - Announce completion and mark the goal as complete.
