# 🧠 Skill: Reddit Deep Research & Sentiment Synthesizer

## Description
Search Reddit discussions for a target topic, scrape community sentiment, extract consensus recommendations, and output a concise executive report.

## Required Tools
- `terminal.web_search(query)`
- `terminal.extract_url_text(url)`
- `knowledge.save_report(filename, content)`

## Execution Rules:
1. Search via DuckDuckGo: `site:reddit.com <topic> "recommendations"`
2. Read the top 3 discussion threads.
3. Ignore promotional spam and bot comments.
4. Synthesize a 3-bullet summary:
   - Consensus Recommendation
   - Known Drawbacks / Caveats
   - Best Alternative Mentioned
5. Output results to `data/reports/reddit_<topic>.md`
6. Speak completion summary via Kokoro TTS.

Up and Running in 2 Minutes

Quickstart Installation Guide

Follow these simple steps on your Windows machine to launch My Desktop Agent.

PowerShell / Command Prompt 
# Step 1: Clone the official open-source repository
git clone https://github.com/prettymuchgavin/MyDesktopAgent.git
cd MyDesktopAgent

Requires Git for Windows and Python 3.10+ (Python 3.11 recommended).

PowerShell / Command Prompt 
# Step 2: Install required Python dependencies
pip install -r requirements.txt

Installs screen capture bindings, audio transcription, Kokoro TTS, and LLM orchestration drivers.

PowerShell / Command Prompt 
# Step 3: Run interactive setup wizard (configures Telegram bot, LLM keys, Ollama)
python setup.py

The guided CLI wizard detects your displays, checks Ollama connectivity, and optionally tests Telegram webhooks.

PowerShell / Command Prompt 
# Step 4: Launch My Desktop Agent & Web Control Center
python main.py

Opens the browser dashboard, activates the global Alt+A voice listener, and listens for Telegram commands.

My Desktop Agent includes a built-in Dangerous Command Safety Gate. Every terminal string is passed through a deterministic heuristic filter before execution, blocking commands like rmdir /s, rm -rf, disk formatting, and core system process termination. You also have an instant Emergency Freeze hotkey (F12) that suspends agent operations immediately.
