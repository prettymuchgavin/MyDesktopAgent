# My Desktop Agent - Knowledge & Reference Guide

## Welcome to your Personal Desktop Agent
This knowledge folder (`data/knowledge/`) is your agent's private document brain. Any `.txt`, `.md`, `.json`, or code files you place here will be automatically indexed and searchable by your agent.

### Example Capabilities
- **Terminal Execution**: The agent can run PowerShell and CMD commands directly.
- **Web Search**: The agent uses fast DuckDuckGo search to retrieve live info.
- **Telegram Remote**: You can control your PC from your phone using Telegram.
- **System Tray Mode**: The agent runs quietly in your Windows taskbar notification area.
